# Our Anniversary Gift

A phone-first anniversary scrapbook for Iris. It is a standalone static site;
it does not change or depend on the Godot game.

## Open it

Open `index.html` in a browser. Keep the `images` folder next to it.

## Photos

The site uses five local photos in `images`: the first-meeting chat, the PUBG
game screenshot, the birthday blind-box photo, and two portraits. The repeated
replacement image was intentionally left out.

The page has no external fonts, scripts, or network dependencies.

The anniversary note on the main page is written in Myanglish. After the
five-second heart celebration, the page reveals a small heart-catching game
and a button to return to the scrapbook.
